# Amortizing Loan Calculator

A Python-based loan amortization calculator that calculates monthly loan payments and generates a detailed repayment schedule.

## Project Overview

This project uses Python to model how an amortizing loan is repaid over time. It calculates the monthly payment, interest, principal repayment, and remaining balance for each payment period.

The project was created as part of my journey into **Python programming, financial modelling, and quantitative finance**.

## Features

- Calculates monthly loan payments
- Converts annual interest rates into monthly rates
- Generates a month-by-month amortization schedule
- Separates each payment into interest and principal
- Tracks the remaining loan balance
- Calculates total interest paid
- Calculates total amount paid over the loan term
- Compares different interest-rate scenarios
- Supports additional payments to help reduce the loan faster

## Example

For a loan of:

- **Principal:** 300,000
- **Annual Interest Rate:** 12%
- **Loan Term:** 10 years

The calculator produces a monthly payment of approximately:

**4,304.13**

It also calculates the interest and principal portions of every monthly payment and tracks the outstanding balance until the loan is fully repaid.
